Why the method matters

Repeatability is what turns a report into assurance.

A finding should be defensible. It must be possible to trace it back to the measured state, the rule or requirement applied to it, the assessor's judgement and the resulting recommendation.

01 · INPUT

Measured state first

Collection starts from live configuration rather than retyped inventory or assumptions.

02 · CONTEXT

Modules follow the environment

The selected modules determine which parts of the cluster stack are collected and which grading recipes apply.

03 · GRADING

No recipe, no verdict

The catalogue separates measurement from judgement. A value can be present without automatically becoming a finding.

04 · ASSESSMENT

Human judgement stays visible

The assessor confirms or refutes findings rather than hiding judgement inside a score.

05 · OUTPUT

One measurement, several views

Findings, delta, residual risk, trend, system documentation and RCA can all draw from the same measured evidence.

06 · LOOP

Follow-up returns to Measure

The scope is not reinvented every quarter. The environment is measured again, creating comparable evidence.

Method + Assurance

The method stays the same. The measured state changes.

That is what makes Q1 through Q4 comparable and lets remediation be verified rather than merely reported as complete.
